## What we're building

An open-source toolkit for AI-powered enterprise content migration and intelligent content operations, centred on the Microsoft 365 platform and Claude as the reasoning engine, connected through open standards (Model Context Protocol).

### Repositories

| Repository | Purpose | Status |
|---|---|---|
| [`spfx-components`](./spfx-components) | Reusable SPFx web parts for modern SharePoint Online | 🚧 In development |
| [`mcp-sharepoint`](./mcp-sharepoint) | Model Context Protocol server exposing SharePoint to Claude and other MCP clients | 📋 Planned Q1 2027 |
| [`claude-skills-sharepoint`](./claude-skills-sharepoint) | Anthropic Skills for SharePoint governance, migration planning, content type design | 📋 Planned Q1 2027 |
| [`migration-agent`](./migration-agent) | Claude-powered migration agent — legacy file shares and content systems to Microsoft 365 | 🎯 Flagship; MVP Q2 2027 |
| [`dms-adapters`](./dms-adapters) | Source-system adapters for `migration-agent` — OpenText, iManage, FileNet and others | 📋 Planned Q3 2027 onward |

## Philosophy

We believe enterprise AI is becoming a multi-vendor architectural concern. Organisations will run Microsoft Copilot, Anthropic Claude, and other AI services alongside one another as a strategic portfolio — not as competing winner-takes-all platforms. Our work supports that reality through open standards, source-available tooling, and vendor-neutral architectural judgement built on deep hands-on experience with both Microsoft and Anthropic stacks.
